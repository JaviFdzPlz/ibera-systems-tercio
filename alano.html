ALANOExtend the geometry. React at the edge.

ALANO is the TERCIO family of attritable forward, remote and mobile mission nodes used to extend sensing, cueing, relay and selected local non-kinetic response functions around obstacles, dead ground and masked approaches.

01 / OPERATIONAL PROBLEM

Terrain hides threats.
It also hides sensors.

Dismounted teams operate in terrain where vegetation, structures, trenches, folds in the ground and short-range masking can limit line of sight and compress warning. Increasing sensor power or transmission strength does not automatically solve a geometry problem.

ALANO addresses this by moving selected sensing, relay or local-response functions forward, laterally, vertically or onto mobile platforms through low-cost nodes designed for bounded autonomy and attrition tolerance.

02 / CAPABILITY LOGIC

Geometry over power.
Local response over complexity.

ALANO extends the architecture without becoming a mandatory dependency. Each node should provide bounded local value, share event-level cues when useful and degrade gracefully when links or neighbouring nodes are lost.

Selected non-kinetic effects may be used locally and reactively to disrupt, delay or complicate an already detected or approaching threat. Persistent deception, false operational patterns and perception shaping remain the role of ARDID.

Boundary rule: ALANO reacts to the threat. ARDID shapes what the adversary believes.

03 / CANDIDATE MVP PATHWAY

CANDIDATE ROADMAP PACKAGE

ALANO Forward Mission Node

One forward, remote or mobile configuration focused on displaced sensing, relay or one bounded local non-kinetic response function. The first demonstrator tests whether placement creates measurable geometry or response value in one agreed scenario.

Entry condition: agreed mission configuration, stable interfaces, mounting concept and a measurable geometry or response question.
FOLLOW-ON FAMILY

ALANO Core & Mission Configurations

Follow-on work develops the common power, processing, communications, event logging, module recognition and standardized mechanical, electrical and data interfaces required to support a bounded family of mission-configured nodes.

Sense, relay and effect functions are verified separately before hybrid configurations or additional mounting kits are introduced.
ALANO-S / Sense

Forward or elevated sensing for agreed threat and terrain conditions.

ALANO-R / Relay

Event-level cue extension and communications support with low-duty-cycle behaviour.

ALANO-E / Effect

Selected local non-kinetic effects such as visual, infrared, acoustic, thermal or short-duration obscuration functions.

ALANO-H / Hybrid

Limited Sense + Relay, Sense + Effect or Relay + Effect combinations where the operational gain justifies added complexity.

04 / DEPLOYMENT & MOUNTING

One node family.
Multiple geometries.

Deployment should be separated from mission function through standardized mounting kits. The same node type may be placed on the ground, attached to structures, carried by vehicles, integrated with UGVs or hosted by suitable aerial platforms.

A UAV may act either as a carrier that deposits the node or as a host that keeps it airborne. Host integration introduces additional mass, power, vibration, aerodynamic and electromagnetic constraints and should therefore be treated as a qualified configuration rather than a universal assumption.

MK-G / Ground

Tripod, stake, hand placement or other bounded ground-deployment concept.

MK-S / Structure

Clamp, rail, pole, tree, wall, roof or prepared-position attachment.

MK-V / Vehicle & UGV

Mechanical or magnetic integration for mobile terrestrial deployment and repositioning.

MK-A / Aerial

Carrier or host integration for multirotor, FPV-UAV or other suitable aerial platforms.

05 / REPRESENTATIVE TEST LOGIC

Prove the geometry gain.
Then prove the local response.

The first ALANO programme should compare a baseline local configuration with one or more displaced-node placements under representative masking. The test question is whether node placement creates useful, timely and reliable additional information or response value.

Sensing, relay and effect functions should be verified separately before hybrid configurations are introduced. Event logic, human authorization, link loss, safe states and replacement burden should be evaluated as part of the same development sequence.

Geometry value

Incremental cueing, coverage or response opportunity created by node placement.

Local effect value

Ability of a selected non-kinetic function to create a bounded disruption or time gain in an agreed scenario.

Attrition tolerance

Operational effect of node loss, replacement burden, serviceability and retrieval options.

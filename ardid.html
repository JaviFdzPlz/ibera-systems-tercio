TERCIO / L4 / DECEPTION & PERCEPTION SHAPING

ARDIDShape what the adversary believes.

ARDID is the TERCIO capability focused on coordinated false signatures, alternate cues and ambiguity before final target commitment. It operates proactively across time and space to influence observation, targeting and decision-making.

01 / OPERATIONAL PROBLEM

Survivability improves when the adversary chooses the wrong reality.

Persistent surveillance, thermal observation and low-cost strike systems increasingly depend on rapid target classification and commitment. Once the correct target is identified, the available response window may be very short.

ARDID acts earlier. It seeks to create credible ambiguity through distributed, bounded and controllable false signatures, activity patterns and alternate cues that complicate target selection before commitment.

02 / DOCTRINAL BOUNDARY

Same hosting platform.
Different function ownership.

ALANO provides the platform, energy, geometry and common communications that forward, remote or mobile nodes need. ARDID uses persistent or sequenced deception effects, which it may place on ALANO-hosted nodes, to shape what an adversary believes before final target commitment.

ALANO hosts and extends geometry. ARDID owns the deception function. ARDID may employ dedicated decoy assets or task compatible ALANO-hosted modules, but the deception logic, sequencing and assessment remain ARDID functions at all times.

03 / CANDIDATE MVP PATHWAY

CANDIDATE ROADMAP PACKAGE

ARDID Controlled Deception Experiment

A supervised, bounded experiment using one agreed threat-observation method and a limited set of false or alternate cues. The purpose is to evaluate whether a controlled deception pattern changes detection, classification, attention or target-selection behaviour under representative conditions.

Development parameters include signature type, persistence, spatial pattern, sequencing, observability, safety, reset criteria and assessment method.
FUTURE GROWTH PATH

Distributed Deception Network

Later work may examine coordinated thermal, visual, acoustic, RF or activity-pattern cues across dedicated assets, mobile platforms and compatible ALANO nodes.

Autonomy, anti-triangulation and adaptive patterning are introduced only after bounded single-pattern experiments establish credible evidence and governance.

04 / REPRESENTATIVE TEST LOGIC

Test the decision effect.
Not only the emitter.

The first ARDID programme should compare baseline observation with one controlled deception pattern under repeatable conditions. The test question is whether the pattern changes where attention is allocated, how targets are classified or which aim point is selected.

Trials should use approved surrogates, controlled safety boundaries, logged timing, independent observation and clearly defined stop conditions.

Perception effect

Changes in detection, classification confidence, attention allocation or selected aim point.

Pattern credibility

Persistence, coherence, environmental fit and resistance to simple cross-checking.

Control discipline

Tasking, timing, deactivation, anti-patterning, traceability and compromise management.

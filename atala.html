TERCIO / L2 / LOCAL & COOPERATIVE EARLY WARNING

ATALAGenerate warning. Preserve human decision space.

ATALA is the TERCIO capability focused on local and cooperative early warning using complementary sensing. Its baseline principle is local utility first: a node should remain useful when disconnected and share only low-duty-cycle event cues when cooperation adds value.

01 / OPERATIONAL PROBLEM

Detection is useful only when it produces action.

Dismounted teams may receive little or no useful warning from systems optimized for larger formations, continuous connectivity or RF-dependent detection. Fibre-optic control and low-signature approaches further weaken any architecture built around a single cue path.

ATALA addresses this gap by exploring a compact local-first warning node that combines complementary sensing, keeps alerts simple and preserves bounded utility even when communications are unavailable.

02 / CAPABILITY LOGIC

Local first.
Cooperative when useful.

ATALA is defined by its role and operational logic rather than by one fixed sensor list. Candidate sensing channels are selected through a jointly governed trade study against the agreed threat set, user needs and verification plan.

The architecture shares cues and confidence rather than assuming perfect tracks. Event-driven, low-duty-cycle communication is preferred over continuous transmission, and the local alert remains the minimum useful behaviour.

03 / CANDIDATE MVP PATHWAY

CANDIDATE ROADMAP PACKAGE

ATALA Local Early-Warning Breadboard

A tightly scoped breadboard intended to test one agreed low-altitude UAS threat set using a deliberately limited combination of sensing channels. The objective is to generate a simple, timely and actionable local cue while controlling nuisance alerts, cognitive burden and own-signature impact.

Development parameters—including sensing mix, alert thresholds, warning distribution and user interface—are established within an integrated team combining ÍBERA system architecture with operational, engineering and test expertise.
FUTURE GROWTH PATH

Cooperative Warning Network

Later work may examine low-duty-cycle event sharing between ATALA nodes and compatible forward nodes, including confidence, direction or alert-state cues. Cooperation is intended to improve coverage without making the network a mandatory dependency.

Multi-node value is matured progressively after local utility and interfaces have been demonstrated.

04 / REPRESENTATIVE TEST LOGIC

Test the alert chain.
Design around the user.

The ATALA development route evaluates the complete path from physical cue to human response. Sensor performance, alert timing, interpretation and operator action are treated as one system-level test question.

ÍBERA Systems provides the system architecture, requirements framework and integration authority. Specialist partners contribute sensing, human-factors, operational, testing, industrial and financing capabilities within a jointly governed programme.

Detection performance

Alert quality

Nuisance-alert causes, confidence handling and actionability.

Human outcome

Alert comprehension, response, cognitive load and interface suitability.
